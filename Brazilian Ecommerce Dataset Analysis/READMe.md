# Brazilian Ecommerce Public Dataset Analysis  

## 📌 Project Overview  
This project analyzes the **Brazilian E-commerce Public Dataset** to gain valuable insights into sales performance, customer behavior, and product trends. Using **Power BI** dashboards, we transformed raw transactional data into interactive visualizations to support decision-making in e-commerce.  

The dataset contains millions of orders placed between **2016 – 2018** across Brazil, including details about customers, sellers, orders, payments, and reviews.  

---

## 🎯 Objectives  
The main objectives of this project were:  
1. **Sales Analysis** – Understand total revenue, orders, payment trends, and top-selling categories.  
2. **Customer Insights** – Identify customer segments, demographics, retention, and customer lifetime value.  
3. **Product Analysis** – Evaluate product sales, review scores, and return rates.  
4. **Regional Insights** – Map regional/state-level contributions to sales and customer distribution.  
5. **Visualization** – Build professional dashboards with filters (by date, state, category, segment) for dynamic exploration.  

---

## 🛠️ What We Did  
✔️ Cleaned and pre-processed raw dataset (missing values, date formatting, currency adjustments).  
✔️ Created **3 Power BI Dashboards**:  
- **Sales Overview Dashboard** → Total revenue, orders, payment breakdown, top-selling categories, sales trend over time.  
- **Customer Insights Dashboard** → Retention rate, segmentation, demographics, CLV, customer value distribution.  
- **Product Analysis Dashboard** → Product sales, review scores, product return rate, revenue by category.  
✔️ Added slicers and filters for **time, state, segment, and category**.  
✔️ Used **charts, maps, KPIs, and treemaps** for deep analysis.  

---

## 🔎 Key Insights Gained  
- **Total Revenue**: 16M BRL+ across 99K orders.  
- **Payment Method**: Credit card dominates (12.54M revenue).  
- **Top Selling Categories**: Furniture, sports, home decor, health & beauty.  
- **Customer Retention**: Very low at 3.12% → huge scope for loyalty programs.  
- **Regional Contribution**: SP (São Paulo), RJ (Rio de Janeiro), MG (Minas Gerais) lead in sales.  
- **Average Review Score**: 3.67 → room for product/service improvement.  
- **Product Return Rate**: High at 62.85% → critical issue for sellers.
